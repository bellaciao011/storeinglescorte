Encontrei o problema. O webhook do Stripe quase certamente está com o STRIPE_WEBHOOK_SECRET errado.

O que acontece: cada endpoint de webhook no Stripe tem seu próprio whsec_... exclusivo. Se você copiou o secret do projeto original, ele não serve para o novo endpoint — a verificação de assinatura falha silenciosamente e o Stripe recebe 400, sem disparar nada.

Como corrigir:

Acesse Stripe → Developers → Webhooks
Verifique se existe um endpoint apontando para:
https://www.mx-panini.site/api/stripe/webhook

Se não existir, crie um novo com esse URL e marque o evento payment_intent.succeeded
Após criar/abrir o endpoint, clique em "Reveal" no campo Signing secret — esse é o whsec_... correto para este projeto
Atualize o STRIPE_WEBHOOK_SECRET na Vercel com esse novo valor
Esse é o motivo mais comum quando um webhook funcionava no projeto original mas não no remix — o secret é único por endpoint, não por conta Stripe.
